## 0.2.0｜固定 0x100 与独立使能／失能

日期：2026-11-02（Asia/Shanghai）。

- 用户确认 send_mit 固定 0x100，增加 enable／disable，并直接使用 GD 流程；未采用 auto_enable 参数草案。
- 35 项 Python 离线检查通过：33 项核心协议／路由检查，2 项实际 CANable 编解码与模拟 USB 组合检查。
- 核对 MIT 黄金载荷与 0x100+node、GD 模式写入 `2F 03 20 00 03 00 00 00`、使能字 1、失能字 2；节点范围仍为 0..127。
- 模拟协议交互覆盖 enable 的两条 SDO → MIT → 自动状态 → disable → 再发 MIT；再次 MIT 不携带使能请求。
  这是协议夹具，不模拟或证明电机物理状态。
- 模式／控制字应答按 index 区分，接受和拒绝都交付；模拟 ADM 模式对象拒绝后，控制字应答仍单独保留。
- enable 首帧或第二帧传输失败立即传播，不继续失败后的帧、不重试，不据发送成功或 ACK 推断功率级状态。
- 两种 CANable 同步接口均核对最终 USB 编码的 mode／enable／0x100 MIT／disable 四帧，不调用 open 或真实 USB。
- editable 安装升级至 0.2.0；构建并独立安装 `c2_v1_sdk-0.2.0-py3-none-any.whl`。
  在 python -I -S、无 CANable 环境运行 33 项核心检查，2 项可选组合检查按预期跳过；包版本／元数据、源码／wheel／安装字节一致。
- 18 份参考文件哈希复核未变，来源快照继续有效。历史旧工具的 0x400 ID 不再作为当前发送入口的预期值。
- 未连接硬件；ADM 对模式对象的实际拒绝、后续使能效果及完整兼容性仍需实机验证。
